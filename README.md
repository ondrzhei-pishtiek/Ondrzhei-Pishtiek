## Я зробив усе як має бути та все працює. Є адмін панель, загальний вебсайт для користувачів з 
іншим відображенням без адмін-інструментів.. Усе поскрінив у ворді, який присутній в цій гілці.
Також є папка майсайт, де присутні всі файли з пайтону. Чисто в теорії, можна вставити в пайтон проєкт
на будь-якому ПК та запустити сервер і працювати з сайтом та сервером й надалі.
